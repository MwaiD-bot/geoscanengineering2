# GeoScan Engineering

A Cloudflare-compatible static website for GeoScan Engineering, built with HTML and CSS and ready to deploy as a static site on Cloudflare Pages or Cloudflare Workers Assets.

Files included:
- index.html
- services.html
- approach.html
- gallery.html
- about.html
- contact.html
- style.css
- assets/logo-mark.svg
- assets/favicon.svg
- wrangler.toml

Upload the project folder directly to Cloudflare Pages or run `wrangler deploy` from the project root.
